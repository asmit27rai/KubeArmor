## Bus Factor

KubeArmor maintains an active maintainer group with multiple contributors capable of reviewing pull requests, managing releases, handling security issues, and maintaining CI/CD infrastructure.

Current estimated project bus factor: >= 3

This estimate is based on:

- Multiple maintainers with repository management access
- Shared release and review responsibilities
- Distributed expertise across runtime enforcement, Kubernetes integration, eBPF, and operator components
- Active participation from maintainers across multiple organizations and institutions
